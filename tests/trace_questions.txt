# Week 5 — the question bank used to build a population of real traces.
# One question per line. Lines starting with # and blank lines are ignored.
#
# Run it with:  python scripts/ask_batch.py
# Every question goes through the normal answer path, so each one is logged as a
# trace. Week 5 then draws a random sample from those traces.
#
# Why more questions than the 20 you need: sampling 20 out of 20 is not sampling.
# A larger population is what makes the random draw meaningful, which is exactly
# what the mentor checks first ("did they read a fair sample?").
#
# The mix is deliberate — clear questions, questions whose answer is in two
# documents, questions that are not in the corpus at all, questions where the
# documents disagree, and vague questions a real user would actually type. The
# vague and conflicting ones are where the interesting failures live.
#
# Kept in step with the documents in data/corpus/ (rewritten 2026-10-11 after the
# corpus changed): nothing here refers to a file that is no longer there.
